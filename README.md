# Sales Performance Dashboard

## 📌 Project Overview

Developed an interactive Power BI dashboard to analyze sales performance across regions, products, categories, and months.

The dashboard provides a consolidated view of revenue, profit, quantity sold, and profit margin to help understand overall sales performance.

## 🎯 Objective

To analyze sales performance and identify patterns across regions, products, categories, and monthly sales trends using an interactive Power BI dashboard.

## 📊 Dashboard Highlights

- Total Revenue: 817K
- Total Profit: 181K
- Total Quantity: 88
- Profit Margin: 0.22
- Sales by Region
- Top 5 Products by Sales
- Sales by Category
- Monthly Sales Trend
- Region and Category filters

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Data Visualization
- Data Analysis

## 📈 Key Analysis

The dashboard analyzes:

- Revenue performance across different regions
- Top-performing products by revenue
- Revenue contribution by category
- Monthly sales trends
- Overall profitability and profit margin
